Berlin — spike no Cloudflare Workers

Esta página é servida pelo mesmo Worker que a API (Static Assets). Requisições a assets estáticos são gratuitas e ilimitadas, então a interface não consome as 100 mil requisições/dia do plano Free.

Rotas

  • GET /api/health
  • GET /api/models — lista de modelos, cache de 5 min no KV
  • POST /api/inspect — prefill (multipart com o campo image)
  • POST /api/edits — multipart com params (JSON) + image_b64
  • GET /api/edits/:id — estado do job
  • GET /api/edits/:id/image — imagem gerada
  • POST /api/hooks/horde — webhook do Horde
  • POST /api/tick — a mesma função do Cron Trigger
  • GET /api/results — últimos jobs
Spike de arquitetura — ver run-local.mjs e README.md.
